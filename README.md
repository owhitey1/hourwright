# Hourwright

UK luxury-watch comparison site. Static HTML generated by `build.py`, product data from Awin retailer feeds.

## Rules built into the code
- Prices, stock, images, specifications and affiliate links come only from retailer Awin feeds (`scripts/fetch_feed.py`). Nothing is generated.
- A feed that looks broken is rejected and the last good data is kept.
- `scripts/launch_check.py` blocks deployment until operator details, Awin publisher ID, a live retailer and real products are in place.
- Analytics loads only after the visitor accepts. Email signup is hidden until a provider is connected.

## Commands
    pip install markdown
    python -m unittest discover tests     # feed logic tests
    python scripts/fetch_feed.py          # needs AWIN_FEED_URL_* environment variables
    python build.py                       # writes dist/
    python scripts/check_links.py
    python scripts/launch_check.py

## Going live
1. Fill in `config.json`: operator_legal_name, operator_address, contact_email, awin_publisher_id.
2. In Awin, join each retailer programme, then set that retailer's `status` to `live` in `config.json`.
3. In Awin Toolbox > Create-a-Feed, create one CSV (gzip) feed URL per retailer with the columns listed at the top of `scripts/fetch_feed.py`.
4. Push this folder to a GitHub repository. Add each feed URL as a repository secret (AWIN_FEED_URL_JURA, AWIN_FEED_URL_GOLDSMITHS, AWIN_FEED_URL_BEAVERBROOKS).
5. Repository Settings > Pages > Source: GitHub Actions. The workflow then fetches feeds, tests, builds and deploys daily at 05:17 UTC.
6. Point the domain's DNS at GitHub Pages and add it under Settings > Pages > Custom domain.
7. Optional: ga4_measurement_id, google_site_verification, bing_site_verification, email_form_action.

## Adding content
- Brand: add an entry to `content/brands.json`.
- Guide: add a Markdown file to `content/guides/` with `title`, `description`, `order`, then `---`.
- Retailer: add to `retailers` in `config.json` and add its feed secret to the workflow.

Fonts: Fraunces and Hanken Grotesk, SIL Open Font License, self-hosted.

## Monitoring and recovery
- The workflow runs daily. If tests, a feed, the build, the link check, the deploy or the live smoke test fails, GitHub emails the repository owner and the previous good site stays online.
- A rejected feed never overwrites `data/products.json`; fix the feed secret or wait for the retailer, then re-run the workflow from the Actions tab.
- To roll back, revert the offending commit on `main`; the next run redeploys.
- Secrets live only in repository Settings > Secrets and variables > Actions. Never commit feed URLs.
